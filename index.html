⚙️ Setup

Cấu hình Supabase, Apps Script API và Telegram webhook.

Supabase







Không đưa service role key lên GitHub Pages. Các key được ẩn trên giao diện và sẽ lưu vào bảng app_settings khi bấm Save settings / Lưu setup lên Supabase. Máy khác chỉ cần có Supabase URL + anon key để Load setup từ database.

Apps Script











Có thể dùng chung Apps Script URL nếu file GAS có cả doGet queue API và doPost Telegram. Domain Group Chat ID là group nhận thông báo tạo domain.
